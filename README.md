# wordcheck

A dependency-free English spelling checker with an embedded dictionary and a
small command-line interface. Uses only the Go standard library.

## Features

- **Embedded dictionary** — 21,082 lowercase English words compiled into the
  binary, so nothing to download or configure.
- **Tokenization** — splits text into words and number tokens with byte
  offsets and line numbers. Apostrophes inside words (`don't`, `rock'n'roll`)
  are kept; `3.14` and `100,000` are recognized as single number tokens.
- **Suggestions** — for every unrecognized word, ranked candidate corrections
  within edit distance 2 (Levenshtein), closest first, then alphabetically.
- **JSON output** — machine-readable reports, a pure JSON document on stdout.
- **In-place replace** — swap a misspelled word for a correction.

## Install and build

```sh
go build ./cmd/wordcheck
```

Builds with `CGO_ENABLED=0` are supported; the package has no cgo or external
dependencies.

## Usage

```
wordcheck [options] FILE...
wordcheck [options]          # read from stdin
```

| Flag | Meaning |
| --- | --- |
| `-replace old=new` | replace every token equal to `old` with `new` in the given files (in place) and print a replacement count |
| `-list-dict` | print the embedded dictionary, one word per line |
| `-max N` | with `-list-dict`, print only the first `N` words |
| `-json` | report misspellings as a JSON array on stdout (the "words checked" summary moves to stderr, keeping stdout parseable) |
| `-ignore-case` | check case-insensitively; suggestions derive from the lowercased word |
| `-ignore-numbers` | skip number tokens entirely (numbers are never flagged) |
| `-no-suggest` | do not attach suggestions to reported words |
| `-version` | print version and exit |
| `-help` | print help and exit |

Exit status: `0` no unrecognized words (or a successful `-replace` / `-list-dict`),
`1` at least one unrecognized word, `2` usage or I/O error.

## Example

`notes.txt`:

```
the quik brown dog jumped over the lazzy wall
hello 3.14 world
```

```console
$ wordcheck notes.txt
notes.txt:1:5 quik -> quick, quit, bulk
notes.txt:1:36 lazzy -> lazy, lady, lay
12 words checked, 2 unrecognized
$ echo $?
1
```

A clean file exits 0:

```console
$ wordcheck clean.txt
9 words checked, 0 unrecognized
$ echo $?
0
```

JSON report (stdout is pure JSON; the count goes to stderr):

```console
$ wordcheck -json notes.txt
12 words checked, 2 unrecognized
[
  {
    "file": "notes.txt",
    "line": 1,
    "column": 5,
    "word": "quik",
    "suggestions": [
      "quick",
      "quit",
      "bulk"
    ]
  },
  {
    "file": "notes.txt",
    "line": 1,
    "column": 36,
    "word": "lazzy",
    "suggestions": [
      "lazy",
      "lady",
      "lay"
    ]
  }
]
```

Fix a typo in place:

```console
$ wordcheck -replace quik=quick notes.txt
notes.txt: 1 replacements
```

## Library

```go
import "github.com/Conedope/wordcheck"

wordcheck.IsKnown("speling")              // false
wordcheck.Suggestions("speling", 5)       // ["spelling", "appling", ...] dist <= 2
wordcheck.Levenshtein("kitten", "sitting") // 3

misses := wordcheck.Check(text, wordcheck.TokenizeOpts{
    IgnoreCase:    true,
    IgnoreNumbers: false,
})
// each Miss has the Token (word, byte offsets, line) and ranked Suggestions

tokens := wordcheck.TokenizeWords("Don't stop 3.14.", wordcheck.TokenizeOpts{})
```
